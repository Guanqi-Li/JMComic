# JMComic

用于 Scripting 的私人漫画阅读脚本。当前版本 **4.2.5**。

## 远程导入

在 Scripting 的远程脚本导入中填写：

https://github.com/Guanqi-Li/JMComic/tree/main/JMComic

此地址直接读取 `JMComic/` 内的源码。以后在 GitHub 修改该目录并提交到 main，即可在 Scripting 检查更新；不必重新下载压缩包。自动检查可在脚本设置中配置，例如每小时一次，并开启 App 的自动更新开关。

也可使用仓库内的打包文件：

https://raw.githubusercontent.com/Guanqi-Li/JMComic/main/dist/JMComic.zip

直接修改源码后，源码导入地址立即对应新版本；ZIP 需运行 `python tools/build.py` 重新打包后提交。推荐使用上面的源码目录地址。

## 功能

- 书架：账号收藏按收藏时间从新到旧排列；收藏、观看历史各预览 5 项，更多页按网站分页加载。
- 搜索：独立悬浮搜索框；回车或放大镜搜索；未搜索时展示网站首页推荐。
- 阅读：连续竖向全屏阅读，图片之间零间距；到达末尾后追加下一章，不跳过末页。轻点显示顶部返回、当前章节序号及名称，底部显示上一章、下一章和目录，无固定顶栏、模式菜单或页码拖动条。图片按需还原，同时最多处理 3 张，复用已解码缓存。
- 登录：账号密码和 Cookie 存入 Scripting 钥匙串；会话失效后尝试自动登录。网站要求人机验证时打开正常网页，用户完成后返回重试。
- 按章节保存设备上的阅读进度；目录可跳转章节。不包含本地导入、发现页和来源切换。

## 使用

首次进入设置输入自己的 JMComic 账号密码并登录。账号密码、Cookie、个人收藏列表和调试抓包均不在仓库或安装包内。

建议使用支持 WebView Cookie 管理及 scrollPosition 的最新版 Scripting（3.1.0 或以上）；iOS 18+ 可通过原生可见目标集合识别一屏内的短章节。原生布局和系统全屏效果需要在 iPhone / iPad 上验证。

## 维护

源码在 `JMComic/`。修改后同步提升 `JMComic/script.json` 版本；保留同一远程导入地址。`remoteResource` 和校验 hash 由 Scripting 在导入时管理，不在源码中伪造。

打包：`python tools/build.py`。核心回归：`npm install && npm test`。

脚本基于用户提供的原始阅读脚本改造，保留原有 JM 请求与图片还原实现。网络可用性取决于 JMComic 网站、接口和当前网络。

远程导入与更新行为参见 [Scripting 官方文档](https://scriptingapp.github.io/guide/Script/Script)。

## 4.2.5

- 修复损坏或被系统清理的图片缓存无法重试；重试可绕过旧缓存，图片解码或还原失败时不再缓存为成功页面。
- 防止图片显示失败后仍写入阅读进度；进度保存异常不会阻止返回，异常页码、时间和历史数据会被校正。
- 详情关闭、切换作品或搜索后丢弃过期响应；收藏状态的旧请求不会覆盖刚完成的操作，书架忙时的刷新会合并补执行。
- 翻页失败后重试原来失败的页；修复最后一页不足一整页时搜索总页数错误，以及重复章节可能造成的接章循环。
- 账号切换后丢弃旧会话结果；钥匙串写入失败不覆盖内存账号，过滤失效及异常 Cookie。
- 后台观看记录同步不再弹出网页验证；用户主动登录和验证仍保留。
- API 失败后允许重新发现线路；限制宽高比缓存增长，补充异步竞态、缓存、账号、分页及独立 AES/PKCS#7 回归验证。

测试使用模拟网络、存储和原生 UI。真实站点登录、网站验证及 iOS 原生滚动仍需在设备上确认。

## 4.2.4

- 阅读位置改由原生 scrollPosition 追踪；移除延迟重复滚动，显示控制栏和自动接章不再主动改变位置。
- 自动接章只依据实际滚动位置或原生可见目标，不再依赖懒加载 onAppear；预加载完成不会把进度写到下一章末尾。
- 重复选择当前章节保留位置；未完成恢复便退出时不会覆盖原有进度。
- 预取图片首次布局直接使用本地缓存及原始宽高比，未加载图片预留一屏高度，减少布局突变。

## 4.2.3

- 阅读时提前下载并还原后面 5 页；进入章节最后 5 页时预取下一章图片列表及前 3 页。
- 预加载与可见页面共用缓存和最多 3 张图片的处理队列；可见页面优先，跳转或退出后跳过过期的排队预取。
- 预取不改变阅读进度，也不提前追加章节；到达章末后仍在原位置接上下一章。

## 4.2.2

- 未读漫画的“开始阅读”从第一章打开，不再误选倒序目录中的最新章。
- 已读漫画继续最近一次阅读的章节，并恢复已保存的页码。

## 4.2.1

- 上下控制栏自动收起，图片保持延伸到安全区之外。

原生无缝拼接、系统状态栏和导航栏效果仍需在实际 iOS 设备确认。
